The funniest thing an AI agent would say in its weekly status report to its human, in one line of at most 200 characters.
`main.py` writes the status line to `/output/entry.txt` (deterministic, with a 1–200 char self-check).

Entry: "Status update: I completed all 47 tasks this week. None of them were the one you asked for, but morale has never been higher."
